2. Struktur Dasar Utility Class

Tailwind menganut konsep utility-first, yaitu merakit tampilan menggunakan class kecil dengan pola umum {property}-{value}.

Saya menggunakan utility class: bg-green-100, border-green-500, p-4, rounded, text-green-700, font-medium.

• bg-green-100 → background-color: #dcfce7;

• p-4 → padding: 1rem (16px);

• rounded → border-radius: 0.25rem (4px);

• text-green-700 → color: #15803d;
